# Ngôi Sao Nhỏ English – Demo Cấp 1 (4–6 tuổi)

Bản demo app học tiếng Anh miễn phí cho trẻ 4–6 tuổi: 22 chủ đề, 84 bài, giọng cô giáo, giữ nút để nói và chấm giọng nói.

- Mở bằng Chrome (Android) hoặc Safari (iPhone), cho phép micro khi được hỏi.
- Tiến độ học chỉ lưu trên thiết bị đang dùng.
- Hình minh họa demo: Microsoft Fluent Emoji (giấy phép MIT).
